# LifeOS — Personal Growth App

Quick scaffold for LifeOS (React + Vite + TypeScript + Tailwind + Supabase).

Getting started:

1. Copy `.env.example` to `.env` and fill in Supabase keys.

```bash
npm install
npm run dev
```

Development:

- Dev server: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`
